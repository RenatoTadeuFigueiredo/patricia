# Patricia — Institutional Website

A responsive, performance-optimized institutional website built with a focus on speed, SEO, and clean user experience.

🔗 **Live:** [https://patriciasenapsi.com.br/]

---

## Overview

Single-page institutional website for a professional services brand, engineered with modern web best practices despite a lightweight HTML/CSS stack — prioritising fast load times, strong SEO, and mobile-first responsiveness.

## Features

- **Responsive design** — mobile-first layout adapting across devices
- **Performance-optimized** — WebP image format, self-hosted Inter font (no external font requests)
- **SEO-ready** — `sitemap.xml`, `robots.txt`, Open Graph meta tags, structured favicons
- **PWA-ready** — `site.webmanifest` with full icon set (16x16 → 512x512)
- **Social sharing** — Open Graph image for rich link previews
- **Privacy-conscious** — contact form with privacy reassurance messaging
- **WhatsApp integration** — direct CTA for instant contact

## Tech Stack

- **HTML5** — semantic, accessible markup
- **CSS3** — responsive layout, custom styling
- **Performance** — WebP images, self-hosted fonts, optimized assets
- **SEO** — meta tags, sitemap, robots.txt, Open Graph

## Project Structure

```
.
├── index.html          # Main page
├── style.css           # Styles
├── fonts/              # Self-hosted Inter font
├── fotos/              # Optimized WebP images
├── docs/               # Documentation
├── favicon.svg         # Vector favicon
├── favicon-{16,32}.png # Raster favicons
├── apple-touch-icon.png
├── android-chrome-{192,512}.png
├── og-image.jpg        # Social sharing image
├── site.webmanifest    # PWA manifest
├── robots.txt          # SEO crawler directives
└── sitemap.xml         # SEO sitemap
```

## Performance & SEO Highlights

- Images converted to **WebP** for reduced payload
- **Self-hosted fonts** eliminate render-blocking external requests
- Complete **favicon set** for all platforms and devices
- **Open Graph** tags for optimized social media sharing
- **Sitemap + robots.txt** for search engine crawlability
